# 使用した素材・ライブラリ

## サービス

- Google Maps Platform（Maps JavaScript API）
- Firebase（Authentication / Cloud Firestore / Cloud Storage / Cloud Functions / Hosting）

## ライブラリ

| 名前 | ライセンス | 用途 |
| --- | --- | --- |
| React / React DOM | MIT | 画面 |
| Vite | MIT | ビルド |
| @vis.gl/react-google-maps | MIT | Google Maps を React で使う |
| firebase（JavaScript SDK） | Apache-2.0 | Firebase との通信 |
| firebase-admin | Apache-2.0 | Cloud Functions からのデータ操作 |
| firebase-functions | MIT | Cloud Functions |
| firebase-tools | MIT | エミュレーターとデプロイ |
| @capacitor/core・@capacitor/android・@capacitor/cli | MIT | Android アプリ化 |
| TypeScript | Apache-2.0 | 型チェック |
| oxlint | MIT | コードの検査 |
| sharp | Apache-2.0 | アプリアイコンの画像生成（開発時のみ。リポジトリには含めていない） |

## フォント（Google Fonts、すべて SIL Open Font License 1.1）

- Noto Sans JP（本文）
- Poppins（ロゴ）
- DotGothic16（ドット絵の演出・レベル表示）

## 画像・アイコン

- アプリのアイコン、ロゴ、地図の印、ドット絵（宝箱・星）は、すべてこのリポジトリのコードで描いたものです。外部の画像素材は使っていません。
- 画面の中のアイコン（地図・フィード・＋・ハート・現在地）は、このリポジトリで作成した SVG です。
- デモ用の投稿写真は、投稿者が自分で撮影したものを使います。

## 開発の補助

- コードの作成に AI（Claude Code）を使用しました。
